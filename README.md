# 무음 셔터 (SilentShutter)

한국판 갤럭시의 **기본 카메라 강제 셔터음**을 끄는 앱입니다. 기본 카메라를 그대로 쓰기 때문에 카메라 기능은 모두 정상적으로 동작합니다. 루팅도 PC도 필요 없어요.

## ⬇️ 다운로드

**[SilentShutter.apk 받기](https://github.com/Ychoib/silent-shutter/releases/latest/download/SilentShutter.apk)**

## 설치 (처음 한 번)

1. **자동 차단 끄기**: 설정 → 보안 및 개인정보 보호 → 자동 차단 → 끔
   (GitHub에서 받은 앱을 설치하고 무선 디버깅을 쓰려면 꺼야 해요. 설정이 끝나면 다시 켜도 됩니다.)
2. 위 링크로 APK를 받아 열고 **설치**를 누르세요. "출처를 알 수 없는 앱" 허용 창이 나오면 허용하세요.
3. **개발자 옵션 켜기**: 설정 → 휴대전화 정보 → 소프트웨어 정보 → **빌드번호**를 7번 누르기
4. 와이파이에 연결한 상태에서 **무음 셔터** 앱을 열고 **[무선 디버깅 열고 페어링 시작]**을 누르세요.
5. 열린 화면에서 **무선 디버깅**을 켜고 **페어링 코드로 기기 페어링**을 누르세요.
6. 알림창을 내려 **무음 셔터** 알림의 **[코드 입력]**에 화면의 6자리 코드를 입력하면 끝!
   (폴드는 분할 화면으로 설정과 앱을 함께 띄우고 앱의 입력칸에 직접 넣어도 돼요.)
7. 카메라 앱을 껐다 켜고, **무음 또는 진동 모드**에서 촬영해 보세요.

설정이 끝나면 무선 디버깅과 개발자 옵션은 꺼도 무음이 유지됩니다.

## 알아두세요

- 이 앱은 휴대폰 자체의 무선 디버깅(ADB) 권한으로 `csc_pref_camera_forced_shuttersound_key` 설정을 `0`으로 바꿉니다. 그러면 셔터음이 해외판처럼 **소리 모드를 따르게** 됩니다.
- **무음·진동 모드에서는 셔터음이 0**입니다. 소리 모드에서는 시스템 음량에 따라 작게 날 수 있어요.
  항상 무음으로 쓰려면: 설정 → 모드 및 루틴 → 루틴 → 조건 "카메라 앱을 열 때" → 동작 "소리 모드: 진동"을 추가하세요.
- 공장 초기화를 하면 다시 설정해야 합니다. 업데이트 후 셔터음이 다시 나면 앱에서 **[무음 켜기]**를 누르세요 (무선 디버깅 켜기 필요).
- 되돌리려면 앱에서 **[원래대로]**를 누르세요.
- 비공식 방법이며 삼성이 향후 업데이트로 막을 수 있습니다. 사용에 따른 책임은 본인에게 있습니다.
- 타인을 몰래 촬영하는 등 사생활을 침해하는 용도로 쓰지 마세요.

## 지원 환경

- Android 11 이상 삼성 갤럭시 (One UI 3 ~ 9). 갤럭시 Z 폴드8 (One UI 9) 기준으로 만들었습니다.

## 빌드

GitHub Actions가 `main` 푸시마다 APK를 빌드해서 Releases에 올립니다.
같은 키로 서명해야 업데이트 설치가 되므로 저장소 Secrets에 `SIGNING_KEYSTORE_BASE64`, `SIGNING_STORE_PASSWORD`, `SIGNING_KEY_ALIAS`, `SIGNING_KEY_PASSWORD`를 설정하세요.
